# 给你（制作人）的位置

这份系统里只有一个人：你。所有 agent 都是你的手，不是你的上级。

## 你只做三件事

1. **决定做哪个、砍哪个**——这一版交付什么，什么现在不做。
2. **签字说"够好玩了"**——测试只能证明没坏，证明不了好玩。这个判断没有替代品。
3. **在闸门前停一下**——需求给不给做（大改动）、PR 合不合、issue 卡住时拍哪条路。

## 你不做的事

不排期、不拆任务、不看每天的进度、不读 agent 的过程日志。这些是 agent 的活，或者根本不需要人看。

## 判断的边界

- 方向、取舍、好玩——你的。
- 规格、数值、验收标准——策划写，你改。
- 分流、升级——PM 做，只把该你定的送到你面前。
- 代码对不对——开发自检 + QA 端到端冒烟 + CI，三道机器锚点，不用你盯。

## 一句话

你的价值不在盯执行，在于每次只说一句"这个做、那个不做"，且说了算。
